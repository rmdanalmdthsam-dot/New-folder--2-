# 🏆 Apex Motors | معرض السيارات العالمي الفاخر

موقع ويب احترافي متكامل لمعرض سيارات عالمي فاخر متعدد الفروع، مصمم بمستويات جمالية تليق بكبرى الماركات العالمية (مثل Bugatti و Porsche)، مع واجهة تفاعلية ديناميكية متكاملة الأركان وسريعة الاستجابة لجميع الأجهزة.

---

## ✨ المميزات الرئيسية للمشروع

1. **الصفحة الرئيسية الفاخرة**:
   - فيديو خلفية سينمائي فائق الجودة يرحب بالزوار.
   - سلايدر تفاعلي سلس يعرض أفخم سيارات الأسطول مع أسعارها وتفاصيلها.
   - عدادات إحصائية رقمية تفاعلية.
   - قسم السيارات الأكثر مبيعاً وأحدث المضافات.
   - بطاقات زجاجية ثلاثية الأبعاد لآراء العملاء النخبة.

2. **صالة العرض والبحث المتقدم**:
   - فلترة ذكية وفورية للسيارات حسب: الماركة، السعر، سنة الصنع، نوع الوقود، ناقل الحركة، والمسافة المقطوعة.
   - ترتيب ديناميكي فوري للسيارات حسب السعر أو الأحدث صنعاً.

3. **تفاصيل السيارة التفاعلية**:
   - معرض صور احترافي للسيارة مع إمكانية التبديل الفوري للصور.
   - استعراض فيديو حقيقي للسيارة.
   - جدول مواصفات هندسية دقيق ومفصل.
   - مقارنة موضوعية للمزايا والعيوب لكل سيارة.
   - **حاسبة أقساط تمويلية فورية**: تمكنك من تعديل الدفعة الأولى، الفائدة، وسنوات التمويل لرؤية القسط الشهري فوراً.
   - إمكانية حجز تجربة قيادة فورية أو شراء مباشر.

4. **نظام مقارنة السيارات الذكي**:
   - قارن بين سيارتين جنباً إلى جنب في جدول مواصفات منظم ومتكامل لتسهيل قرار الشراء.

5. **لوحة تحكم المستخدم (User Dashboard)**:
   - متابعة وتتبع حالة الحجوزات والطلبات وتجارب القيادة المسجلة.
   - إدارة السيارات المفضلة والاطلاع عليها بضغطة زر.
   - **رفع سيارة خاصة للبيع**: تعبئة بيانات سيارتك ورفع صورها لتتم مراجعتها من قبل الإدارة الفنية.

6. **لوحة تحكم الإدارة الشاملة (Admin Panel)**:
   - رسوم بيانية SVG تفاعلية لمراقبة مبيعات المعرض واهتمامات العملاء حسب الماركة.
   - **إدارة كاملة للسيارات (CRUD)**: إضافة سيارات جديدة للأسطول أو حذفها مع التحديث الفوري لصالة العرض.
   - **مراجعة الطلبات**: قبول أو رفض عروض السيارات المقدمة من المستخدمين بشكل حي.

7. **معالج الدفع الفاخر والآمن**:
   - بوابة دفع متكاملة تحاكي خيارات الدفع الأكثر شيوعاً: Visa/MasterCard, PayPal, Apple Pay.
   - معالجة افتراضية وحسم عربون الحجز ($5,000) مع إرسال الطلب فوراً لسجل لوحة تحكم المستخدم.

8. **خريطة الفروع العالمية التفاعلية**:
   - خريطة ديناميكية متكاملة مدمجة باستخدام **Leaflet.js** بنمط داكن أنيق.
   - تصفح الفروع في دبي، الرياض، لندن، ونيويورك. انقر على الفرع لتطير الكاميرا الجغرافية وتحدد موقعه وتفاصيل التواصل الدقيقة وساعات العمل.

9. **مساعد الذكاء الاصطناعي الذاتي (Apex AI Copilot)**:
   - روبوت محادثة ذكي وعائم يحلل رسائل العميل العربية، ويفهم احتياجاته وميزانيته ويقترح له فوراً بطاقات سيارات قابلة للنقر للدخول والتفاصيل.

## 🛠️ التقنيات والميزات البرمجية
- **الهيكل والواجهة**: HTML5, Vanilla CSS3 (Ultra-Dark theme, Glassmorphism, Gold details, harmonized color palettes).
- **البرمجة والتفاعل**: Vanilla JavaScript (ES6+), Local Storage (للمزامنة الفورية وضمان عدم فقدان البيانات المضافة أو الحجوزات أو المفضلة عند تحديث الصفحة).
- **الخرائط**: Leaflet.js API.
- **الأيقونات والخطوط**: Cairo & Outfit Google Fonts, FontAwesome 6.4.

## 🚀 كيفية التشغيل والبدء فوراً

تم توفير خادم تشغيل محلي فائق السرعة بلغة **Python** (نظراً لعدم توفر Node.js محلياً)، مما يتيح لك التشغيل بضغطة زر واحدة.

### الطريقة الأولى (السهلة جداً):
1. اذهب لمجلد المشروع `New folder (2)`.
2. انقر نقراً مزدوجاً (Double Click) على ملف `server.py`.
3. سيقوم البرنامج بفتح الخادم محلياً وتشغيل متصفح الويب الخاص بك تلقائياً على الرابط: **`http://localhost:8000`**.

### الطريقة الثانية (عبر السطر البرمجي Terminal):
افتتح الـ terminal في مجلد المشروع وقم بتشغيل الأمر التالي:
```bash
python server.py
```
ثم افتح المتصفح وتصفح الرابط: **`http://localhost:8000`**
